# [Directional Positioning] Joint TDOA-PDOA Positioning Method Based on Particle Swarm Optimization [Includes MATLAB Code]

Abstract:
The estimation of target position is crucial for many applications such as tracking, navigation, and data communication. The main advantage of estimating location based on Time Difference of Arrival (TDOA) is that it does not require synchronization between the sender and receiver. The Probabilistic Differential Position of Arrival (PDOA) provides additional information that can be used to improve the position estimation performance. There is no literature reported on the joint use of TDOA and PDOA for localization. In this letter, we propose a new method that combines TDOA and PDOA to achieve improved position estimation. In the proposed method, an initial position estimate is obtained by optimizing the TDOA cost function. Subsequently, the PDOA or a hybrid TDOA-PDOA cost function is optimized using a Particle Swarm Optimizer to obtain the final position estimate. Simulation results show that the proposed method significantly and reasonably improves the localization performance compared to the pure TDOA method.
I. Introduction:
Existing and future wireless communication technologies require precise real-time localization and tracking methods. Position information is important for various applications such as target monitoring [1], wireless sensor networks [2], navigation [3], unmanned aerial vehicle (UAV) localization [4], and connected vehicles [5]. Surveys on localization techniques and systems can be found in [6], [7].
The use of TDOA-based localization algorithms is mainly due to the fact that there is no need for synchronization between the target and anchor points. Two anchor points share the same timing so that the TDOA information between different anchor points can be estimated, thereby obtaining the position. There are mainly two types of solutions to solve nonlinear localization problems using TDOA measurements. One solution is linearization, followed by least squares (LS) estimation. Although linearization has obvious advantages in simplifying these algorithms, the same linearization operation makes these algorithms more sensitive to noise [9], [10]. Another approach is to formulate the localization task as a non-convex optimization problem, which can be solved using iterative optimization methods [11], [12] or convex relaxation methods [13], [14].

IV. Conclusion
The paper proposes a localization method that uses both Time Difference of Arrival (TDOA) and Phase Difference of Arrival (PDOA) measurements. Two cost functions are introduced: one that only utilizes PDOA information, and another that employs a joint function based on the measurements of both TDOA and PDOA. The particle swarm optimization algorithm (PSO) is employed to minimize the suggested cost function and obtain the final position of the target. The position estimation based on TDOA helps in initializing the PSO. Numerical results show that the proposed method significantly outperforms the baseline method without utilizing PDOA information. The performance of the proposed method also remains close to the estimated lower bound for moderate SNR values. The performance of the proposed method depends on the result of the TDOA estimation and the size of the particle swarm, which determines the computational complexity of the proposed method. Simulation results indicate that the benefits of the proposed method can be achieved with a moderate group size.
